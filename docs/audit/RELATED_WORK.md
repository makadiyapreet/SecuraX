## Verified Academic Citations

1. **Zhou et al. (2019) — Devign:**  
   *Effective Vulnerability Identification by Learning Comprehensive Program Semantics via Graph Neural Networks.* NeurIPS 2019.  
   *Relevance:* Pioneered the extraction of AST, Control Flow Graphs (CFG), and Data Flow Graphs (DFG) for vulnerability detection.

2. **Li et al. (2018) — SySeVR:**  
   *A Framework for Using Deep Learning to Detect Software Vulnerabilities.* IEEE TDSC 2018.  
   *Relevance:* Established the concept of syntax-based and semantics-based vulnerability slices.

3. **Fu & Tantithamthavorn (2022) — LineVul:**  
   *A Transformer-based Line-Level Vulnerability Prediction.* MSR 2022.  
   *Relevance:* Demonstrated self-attention weight pooling for line-level vulnerability attribution, forming the theoretical basis of SecuraX Phase 7 Option C.

4. **Chakraborty et al. (2021) — Deep Learning for Vulnerability Detection:**  
   *Are We There Yet?* IEEE TSE 2021.  
   *Relevance:* Highlighted severe dataset duplication and synthetic distribution shifts in Big-Vul and synthetic benchmarks.

5. **Bhandari et al. (2021) — CVEFixes:**  
   *A Comprehensive Dataset of Vulnerabilities and Fixes.* MSR 2021.  
   *Relevance:* Source of authentic in-the-wild before/after vulnerability fix commit pairs used for SecuraX held-out generalization testing.

6. **Chen et al. (2023) — DiverseVul:**  
   *A New Vulnerable Source Code Dataset for Deep Learning.* IEEE S&P 2023.  
   *Relevance:* Massive 300,000+ multi-project C/C++ dataset integrated into SecuraX Tier 1 benchmark.

7. **Wang et al. (2021) — CodeT5:**  
   *Identifier-aware Unified Pre-trained Encoder-Decoder Models for Code Understanding and Generation.* EMNLP 2021.  
   *Relevance:* Backbone encoder-decoder model used in SecuraX Tier 2 PHP and Tier 3 multi-language models.

8. **Guo et al. (2020) — GraphCodeBERT:**  
   *Pre-training Code Representations with Data Flow.* ICLR 2021.  
   *Relevance:* Primary encoder backbone for C, C++, and Python vulnerability classification.
